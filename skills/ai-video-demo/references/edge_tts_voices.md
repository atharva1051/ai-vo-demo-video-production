# Edge-TTS Voice Reference Guide

Microsoft Edge TTS provides neural voices that are suited for professional software screencast demos.

## Recommended Female Voices for Product Demos

| Voice Identifier | Tone / Style | Pacing Guideline | Best For |
|---|---|---|---|
| `en-US-JennyNeural` | Clear, professional, friendly | `+15%` to `+25%` | High-tempo software demos, IDE tours, feature run-throughs |
| `en-US-AriaNeural` | Confident, articulate, crisp | `+10%` to `+20%` | Executive presentations, news-style overview, webinars |
| `en-US-EmmaMultilingualNeural` | Cheerful, conversational | `+15%` to `+20%` | Casual onboarding, user guides, quick tips |
| `en-US-AvaNeural` | Warm, expressive | `+10%` to `+18%` | Workflow tutorials, copilot demonstrations |
| `en-GB-SoniaNeural` | British accent, sophisticated | `+10%` to `+15%` | Enterprise tooling, documentation demos |

## Speech Rate Rules of Thumb

- **Standard pace**: `+0%` (~140-150 words/minute).
- **Modern demo pace**: `+15%` to `+20%` (~170-190 words/minute). Keeps viewers engaged.
- **Fast demo / speedrun**: `+22%` to `+26%` (~200-220 words/minute). Ideal for fitting 3+ minute screen recordings under 90 seconds while maintaining 100% clarity.
- **Above +30%**: Not recommended unless intentionally fast; syllables can blur.
